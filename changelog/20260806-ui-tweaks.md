### Tweak 1 — hide the postcode (scope chosen by the user: "template only")

**Hide, not remove.** Only the Location box in `app/templates/workspace_edit.html` goes. Three
layers are deliberately left standing: `SimulationConfig.postcode`, the `simconfig_store`
round-trip, and the `if "postcode" in form:` branch in `POST /w/{id}/edit`
(`app/main.py:490`). Rationale: an already-stored postcode keeps its value, and restoring the
box when a reader exists is a one-hunk edit rather than a re-plumbing.

**The POST guard is the load-bearing part.** With no input rendered, `postcode` is absent from
the submitted body, so the guard skips and the stored value is untouched. Were the branch
unguarded (`candidate.postcode = form.get("postcode") or ""`), hiding the input would blank the
stored value on every save — the same absent-vs-empty distinction the `sections` marker exists
to preserve for checkboxes, and the shape of three data-loss defects earlier in this build.
This was verified directly (below), not just read.

Rejected alternatives: removing the POST branch too (makes the field unreachable and the
restore a two-layer edit for no real gain); full removal from the model and store (loses stored
values and rewrites the persistence tests — far more than "hide" asks for).

### Tweak 2 — `[ Configure workspace ]` → `[ Configure analysis ]`

Scope chosen by the user: code + both locale catalogs + the spec, so `docs/specs/20-workspaces-ux.md`
keeps describing the shipped UI rather than drifting from it. The Dutch string follows the
existing `[ Configure data ]` entry's phrasing so the two buttons stay parallel on the card.

**Concern raised before implementing, and overruled by the user:** the renamed pair reads
`[ Configure data ] [ Configure analysis ]`, where "analysis" is the whole workspace and "data"
is one part of it — the two no longer name things at the same level, which the previous pair
did. The user weighed this against consistency with `[ Delete analysis ]` and chose the rename.
Recorded here so the trade-off is visible if the labels are revisited.
