{# _msg.html — render a view-model message: translate first, then interpolate. One macro, `msg(m)`, and one reason for it: view-models used to hand the templates display strings they had already assembled with f-strings, so the msgid the template's `_()` looked up was a runtime value that matched no catalog entry. `pybabel extract` never saw those strings and a Dutch reader got them in English. The fix is for the view-model to emit the constant msgid and the runtime values SEPARATELY — `app/results_view._msg` / `._msg_n` build the pair — and for the rendering to do the two steps in order: translate the msgid → substitute %(name)s (app/i18n.interpolate, newstyle=False) Not the other way round: substituting first would produce the same unextractable runtime string the defect is made of. `msg(m)` accepts either shape, deliberately: * a PAIR — {"msgid": …, "params": {…}}, optionally with "plural" + "n" for a count-driven message, which is rendered through ngettext so "1 interval" / "2 intervals" both come out right (and so a language with three plural forms can have them); * a BARE STRING — translated through `_()` alone. The bare-string branch is not legacy tolerance for its own sake. A view-model field that is a CONSTANT sentence — no figures to hold out — has nothing to interpolate, so wrapping it in a dict would add a shape without adding meaning; `_N`-marked literals (app/sample_data.py's role labels, KPI titles, breakdown labels and its one fixed register line) go through this branch. The pair branch is for the fields that carry runtime values. `params` may be absent or empty; `template % {}` is a no-op, so no branch is needed for it. A PARAM MAY ITSELF BE A MESSAGE, and is then rendered through this same macro before being substituted. That is what makes an embedded *label* translatable. A resolution label ("hourly", "15-min" — app/data_view._fmt_res) is a word, not a figure, and it appears inside half a dozen larger sentences; the label cannot be baked into each of those msgids without multiplying them by the number of resolutions, and it cannot be passed as a bare string either, because interpolation runs AFTER translation and so never touches a raw value. Wrapping it as a nested message gets it translated on its own first, then substituted. Only one level is needed in practice, but the recursion is unbounded because the macro simply calls itself. EMPTY AND MISSING VALUES RENDER AS NOTHING, and that guard is load-bearing rather than defensive tidiness. In gettext the empty msgid is the catalog's own METADATA entry, so `_('')` returns the whole PO header — "Project-Id-Version: … POT-Creation-Date: …" — straight onto the page. A None renders the string "None". Both are the kind of thing a caller produces by accident (a field the view-model left unset), and neither should ever be visible, so they are filtered here once rather than guarded at each of the call sites. #} {%- macro msg(m) -%} {%- if not m -%} {#- empty / None / missing: render nothing. See the header — `_('')` is the PO metadata block. -#} {%- elif m is mapping -%} {#- Render any param that is itself a message, so an embedded label is translated before it is substituted (see the header). Non-message params pass through untouched, and are escaped by the Markup substitution below. A nested render comes back as Markup — already escaped once, by its own autoescaped body — and Markup substitution passes it through unchanged rather than escaping it a second time. -#} {%- set p = {} -%} {%- for k, v in (m.params or {}).items() -%} {%- set _ = p.update({k: (msg(v) if (v is mapping and v.msgid is defined) else v)}) -%} {%- endfor -%} {#- `| e` on the TRANSLATED msgid, then `| safe` on the result. A translated msgid is trusted text, so escaping it is a no-op in practice, but it turns the string into Markup, and `Markup.__mod__` escapes each substituted value exactly once — passing an already-escaped nested render through unchanged and escaping a raw data value. Doing it the other way (a plain `str % values` whose result is escaped by the outer `{{ }}`) escapes a nested render twice. -#} {%- if m.plural is defined -%} {{- ngettext(m.msgid, m.plural, m.n) | e | interpolate(**p) | safe -}} {%- else -%} {{- _(m.msgid) | e | interpolate(**p) | safe -}} {%- endif -%} {%- else -%} {{- _(m) -}} {%- endif -%} {%- endmacro -%}
