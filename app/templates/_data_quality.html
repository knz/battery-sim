Rendering one raw would print the dict; wrapping one in `_()` would look up a runtime string matching no catalog entry — which is exactly the defect the pairs exist to fix. The macro also accepts a bare string, which is what app/sample_data.py still supplies for the same fields. It also formats a FIGURE, and this box's counts are figures. They arrive as `i18n.num()` pairs (a number plus the name of a convention) rather than as text, because Dutch groups thousands with a point where English uses a comma — "8.760 intervallen" against "8,760 intervals" — and the view-model runs before the locale is known. Two blocks are conditional on computations that are later increments (§6.3 load reconstruction, §6.2's price-granularity warning): they are rendered only when the view-model produced one, so a dataset that has not reached them simply omits the alert rather than showing an empty one.
